# Nova Code Implementation Plan

**Goal:** Replace the Plugin Lab landing page with the approved Nova Code workbench, retaining the existing catalog and proposal workflows, and deliver a durable, authenticated, sandboxed presentation/export plugin development loop.

**Architecture:** Next.js UI/API reuse Plugin Lab email identity and operator authorization. PostgreSQL stores encrypted sessions and durable leased jobs. A separate worker calls Qwen/DeepSeek and executes generated TypeScript only inside a locked-down container; a trusted renderer previews validated declarative results in an opaque-origin sandbox iframe. Generated drafts never enter the production plugin registry automatically.

**Tech stack:** Existing Next.js/React/TypeScript/pg/esbuild/node:test; separate Docker/gVisor worker; existing notification sender.
