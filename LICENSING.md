# ENA.HK licensing and source-distribution policy

This repository's default code license is GPL-3.0-only. The complete license
text is in `LICENSE`. The bundled `jena-js` runtime is also GPL-3.0-only.

Documentation created for ENA Plugin Lab is intended to use CC-BY-4.0 unless a
file states otherwise. Sample datasets must carry their own license; an entry
marked `NOASSERTION` is not cleared for redistribution and cannot become a
Production plugin fixture.

An idea submitted to Plugin Lab is not automatically licensed under the code
license. The proposer retains copyright and pre-existing intellectual property
and grants only the limited permission needed to evaluate the proposal. A
public summary requires separate display consent. Code enters this repository
only after the contributor accepts the contribution terms and supplies the
required Developer Certificate of Origin sign-off.

Any plugin linked into the same Open ENA application and jENA runtime must use a
license determined in writing to be compatible with GPL-3.0-only before it may
enter the Production allowlist. A commissioned, proprietary, dual-licensed, or
otherwise exceptional arrangement requires a separate written licensing
decision before co-design produces code.

Publication must make the corresponding source, build instructions, notices,
license text, exact version, and third-party notices available from a durable
public source link. In-product attribution alone is not the complete source-
distribution process.

This file records the project's implementation policy; it is not legal advice.
The owner must approve the release configuration, and qualified licensing
advice should be obtained when ownership, upstream derivation, dual licensing,
or commercial distribution is unclear.
